AI Models

The Technology Stack

Stage 1
🧠

MobileNet V2

Leaf Validator & Gatekeeper

The first layer of defense. MobileNet V2 analyzes every uploaded image and classifies it as either a leaf or non-leaf before allowing it through to YOLO.

This prevents false predictions on random images — if someone uploads a car photo, MobileNet rejects it immediately.

Architecture MobileNet V2 (pretrained ImageNet)
Input Size 224 × 224 px
Classes leaf / non_leaf
Threshold ≥ 70% confidence to pass
Framework PyTorch + torchvision
Stage 2
🔥

YOLO v11

Disease Classifier

The core detection engine. YOLOv8 (You Only Look Once) is used in classification mode to identify which tomato disease is present in the leaf image.

Trained on the PlantVillage dataset with tomato disease classes. Returns the top-1 disease prediction with confidence score.

Architecture YOLOv11 Classify
Dataset PlantVillage (Tomato)
Classes 10 disease + healthy
Output Top-1 class + confidence %
Framework Ultralytics
Backend
🐍

Flask

Web Server & API Layer

Flask serves as the lightweight Python web framework that ties everything together — handling image uploads, running both AI models, and rendering results back to the user.

The risk_analysis.py module maps disease predictions to risk levels and treatment recommendations.

Framework Flask (Python)
Template Engine Jinja2
Routes / and /predict-ui
File Storage static/uploads/
Mode Development (debug=True)
🍅

Current Scope: Tomato Dataset

The current version is trained exclusively on tomato crops from the PlantVillage dataset. The AI can recognize 10 tomato diseases plus healthy plant states.

Tomato - Bacterial Spot Tomato - Early Blight Tomato - Late Blight Tomato - Leaf Mold Tomato - Septoria Leaf Spot Tomato - Spider Mites Tomato - Target Spot Tomato - Mosaic Virus Tomato - Yellow Leaf Curl Tomato - Healthy
