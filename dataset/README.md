\# Dataset



The project uses a tomato leaf disease image dataset for training and validation.



\## Dataset Split



| Dataset | Images |

|---|---:|

| Training | 10,000 |

| Validation | 1,000 |

| Total | 11,000 |



\## Classes



The dataset contains 10 tomato leaf classes:



1\. Bacterial Spot

2\. Early Blight

3\. Healthy

4\. Late Blight

5\. Leaf Mold

6\. Septoria Leaf Spot

7\. Spider Mites / Two-Spotted Spider Mite

8\. Target Spot

9\. Tomato Mosaic Virus

10\. Tomato Yellow Leaf Curl Virus
